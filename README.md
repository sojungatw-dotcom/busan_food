# 부산한끼

부산광역시 구군 모범음식점 API를 활용한 랜덤 음식점 추천 서비스입니다. 지역·음식 종류·메뉴 검색, 연속 중복을 피한 추천, 지도 검색, 브라우저에 저장하는 찜 목록을 제공합니다.

## 실행

Node.js 22.13 이상이 필요합니다. 의존성이 없다면 `npm install`을 먼저 실행하세요.

```bash
bash scripts/start.command
```

브라우저에서 http://127.0.0.1:3000 을 여세요. 키 등록 전에는 첨부 API 문서의 2018년 예시 7곳을 명확히 표시하는 미리보기로 실행됩니다. 기존 포트폴리오 홈 파일은 로컬 `work/previous-site/`에 보관했습니다.

## API 키 등록

1. [공공데이터포털 API 페이지](https://www.data.go.kr/data/15034029/openapi.do)에서 **활용신청**을 완료합니다.
2. **마이페이지 → 데이터활용 → Open API → 활용신청 현황**에서 승인 상태와 일반 인증키를 확인합니다.
3. 프로젝트 폴더의 터미널에서 아래 명령을 실행하세요.

```bash
bash scripts/register-key.command
```

`인증키 입력:`이 나오면 **키만 붙여넣고 Enter**를 누르세요. 입력 중 글자나 별표가 보이지 않는 것이 정상입니다. 명령줄 인자로 키를 쓰거나 채팅에 키를 붙여넣지 마세요. Decoding/Encoding 키 모두 처리합니다.

4. 페이지의 **데이터 새로고침**을 누르면 실제 API 데이터로 전환됩니다. 서버를 다시 시작할 필요가 없습니다.

Mac Finder에서 `scripts/register-key.command`를 더블클릭해도 등록할 수 있습니다. 재등록할 때는 같은 명령을 실행하세요. 이 스크립트는 키를 화면이나 셸 기록에 출력하지 않습니다.

## 구성과 보안

- 브라우저 → 같은 서버의 `/api/restaurants` → 부산 공공데이터 API 순으로 요청합니다.
- 키는 서버 전용 변수 `BUSAN_API_KEY`로 프로젝트 `.env`에 저장됩니다. 파일 권한은 소유자만 읽고 쓸 수 있는 `600`입니다.
- `.env`와 변형 파일은 `.gitignore`에 포함되며 `.env.example`에는 키가 없습니다. `NEXT_PUBLIC_` 환경변수를 사용하지 않습니다.
- 프런트엔드·HTML·API 응답에 인증키와 외부 API 요청 URL을 포함하지 않습니다. 공급자의 원문 오류도 노출하지 않습니다.
- API는 HTTPS로 호출하고 모든 페이지를 조회해 전체 음식점을 추천 후보로 사용합니다. 서버 메모리에 30분 동안 캐시하며, 같은 키의 동시 요청을 합칩니다. 화면 새로고침도 유효한 캐시를 재사용합니다.
- 키 변경 시 캐시가 구분됩니다. 인증 실패·연결 실패·한도 초과는 안전한 한국어 오류를 표시합니다. 키가 있는데 실패한 경우 예시 데이터로 바꾸지 않습니다.
- 찜은 이 브라우저의 localStorage에 보관됩니다. 다른 브라우저와 공유되지 않습니다. 문서 예시로 찜한 항목은 2018년 기준이며 실제 API 조회 후에도 과거 기준일로 표시됩니다.
- 로컬 서버는 `127.0.0.1`에만 바인딩합니다. 공개 배포는 별도의 서버 보안 및 환경변수 설정이 필요합니다.

- 모범음식점 지정 정보와 메뉴·전화번호는 자료 기준일의 정보입니다. 방문 전에 영업 여부를 확인하세요.

## 검증

```bash
npm test
npm run build
```

키가 없는 환경에서도 모의 API로 전체 페이지 수집·인증 오류·키 인코딩·응답 정규화·안전한 키 저장을 검증합니다. 실제 키의 유효성과 공급자 연결은 키 등록 후 확인할 수 있습니다.

## 음식점 근처 주차장 추천

추천 결과 아래에서 전국주차장정보표준데이터를 연결해 **부산 내 직선거리 2km 이내, 가까운 순 최대 5곳**을 안내합니다. 주차장 지도, 기본·추가 요금, 주차구획수, 평일·토요일·공휴일 운영시간, 자료 기준일을 제공합니다. 거리는 도보·차량 경로 거리가 아니며, 총 주차구획수는 실시간 잔여 주차면이 아닙니다. 좌표가 없는 주차장은 제외하며, 음식점 좌표가 없으면 거리순 추천 대신 지도 검색을 제공합니다.

1. [전국주차장정보표준데이터](https://www.data.go.kr/data/15012896/standard.do)의 **오픈 API → 활용신청**을 완료하세요.
2. 아래 명령을 실행하고 해당 서비스에 승인된 일반 인증키를 숨김 입력하세요.

```bash
bash scripts/register-parking-key.command
```

3. 웹에서 음식점을 추천받고 주차장 영역의 **다시 조회**를 누르세요. 기존 음식점 키 `BUSAN_API_KEY`는 보존하며, 주차장 키만 `.env`의 `PARKING_API_KEY`에 저장합니다. 같은 인증키를 쓰더라도 두 API 각각의 활용승인이 필요합니다.

브라우저는 내부 `/api/parking?lat=음식점위도&lng=음식점경도`만 호출합니다. 주차장 키는 서버에서만 읽습니다. 공급자의 전국 데이터를 전체 페이지로 조회한 뒤, 서버에서 도로명·지번 주소에 부산이 포함된 주차장을 선별하고 주차장관리번호로 중복을 제거합니다. 공급자 주소 검색에 `부산`만 보내면 0건이 반환되므로 주소 부분검색에 의존하지 않습니다. 결과는 30분간 서버 메모리에 캐시하며 실패하거나 일부 페이지만 수집되면 성공 데이터로 표시하지 않습니다. 최초 조회는 데이터 수에 따라 잠시 걸릴 수 있습니다.

키가 없을 때 주차장 예시를 만들어 표시하지 않고 등록 안내를 제공합니다. 음식점 미리보기의 좌표는 첨부 문서의 2018년 예시이므로 현재 위치와 다를 수 있습니다. 실제 주차장 API 연결은 승인된 키를 등록한 후 확인할 수 있습니다.

## Vercel 배포

1. Vercel에서 GitHub 저장소 `sojungatw-dotcom/busan_food`를 Import합니다.
2. Framework Preset은 **Next.js**, Root Directory는 저장소 루트로 선택합니다. 기본 설치·빌드 설정을 사용하세요 (`pnpm-lock.yaml` 포함).
3. 프로젝트의 **Settings → Environment Variables**에 아래 두 변수를 추가합니다. 값은 로컬 `.env`에 등록한 각각의 실제 API 키입니다.

| 환경변수 이름 | 값 |
| --- | --- |
| `BUSAN_API_KEY` | 부산 모범음식점 API에 승인된 키 |
| `PARKING_API_KEY` | 전국주차장정보표준데이터 API에 승인된 키 |

Production에 적용하고 Preview 배포에서도 사용할 경우 Preview에도 추가합니다. `NEXT_PUBLIC_` 접두사는 붙이지 마세요. `.env` 파일을 GitHub에 업로드하거나 사이트 화면에 입력하지 않습니다. `.env.example`에는 빈 설정 이름만 포함되어 있습니다.

4. Deploy를 실행합니다. 배포 후 환경변수를 변경했다면 Redeploy하세요.

Vercel에서는 서버 환경변수만 사용하며 로컬 `.env` 파일이 필요하지 않습니다. 두 API 라우트는 Node.js 함수로 실행되고 최대 실행시간을 60초로 설정했습니다. 최초 주차장 조회 시 전국 데이터를 불러오므로 잠시 걸릴 수 있으며, 30분 메모리 캐시는 실행 인스턴스마다 별도로 유지됩니다.

참고: [Vercel 환경변수](https://vercel.com/docs/environment-variables), [Vercel Next.js 배포](https://vercel.com/docs/frameworks/full-stack/nextjs).

## 네이버 지도 검색

지도 링크는 네이버 장소 고유번호(Place ID)를 보유한 직접 연결이 아니라 **부산 + 구·군 + 업소명** 검색입니다. 전체 도로명주소와 층·호수를 업소명에 붙이면 관련 없는 결과나 검색 실패가 발생할 수 있어 검색어를 간결하게 구성합니다. 동명 업소를 구분할 수 있도록 추천 결과와 찜·최근 목록에 **주소로 위치 확인** 링크를 함께 제공합니다. 주소 검색에서는 괄호 설명과 쉼표 뒤의 층·호수 정보를 제외하고 도로명·번지를 사용합니다. 주차장 지도 링크에도 같은 방식을 적용합니다.
